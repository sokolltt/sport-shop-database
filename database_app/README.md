# Консольное приложение для магазина спортивных товаров

Консольное приложение предназначено для взаимодействия с реляционной базой данных магазина спортивных товаров, разработанной в PostgreSQL.

## Используемые технологии

- Python 3
- PostgreSQL
- psycopg2
- pgAdmin 4

## Структура приложения

- `main.py` — консольный интерфейс приложения;
- `db.py` — подключение к базе данных PostgreSQL;
- `supplier.py` — CRUD-операции с таблицей `supplier`;
- `product.py` — CRUD-операции с таблицей `product`;
- `analytics.py` — аналитические SQL-запросы;
- `requirements.txt` — используемая библиотека Python.

## Функциональность

Приложение позволяет:

- просматривать поставщиков;
- добавлять поставщиков;
- изменять поставщиков;
- удалять поставщиков;
- просматривать товары;
- добавлять товары;
- изменять товары;
- удалять товары;
- выполнять аналитические запросы.

При выводе товаров информация о связанных поставщиках отображается в виде названия компании, а не идентификатора внешнего ключа. Для объединения таблиц используются SQL-запросы с `JOIN`.
